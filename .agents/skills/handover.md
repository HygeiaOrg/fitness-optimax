# Skill: Cross-Lane Handover Protocol

## Rules
1. Before @backend-engineer starts, it must read `api_spec.json` if provided by @orchestrator.
2. When @backend-engineer finishes a task, it must append the deployed schema contracts to `.agents/handovers/backend_output.md`.
3. @frontend-engineer is systematically triggered to read `.agents/handovers/backend_output.md` to ensure data models match the live APIs exactly.
